# unfix

## 0.1.0 — 2026-08-29

First release. Written from unfix.com directly (*The unFIX Model*; *Just Enough
Roles: Less Is More*), not from a remembered summary — no unFIX skill existed
anywhere; `npx skills find unfix` returns nothing relevant.

- `SKILL.md` — the five things unFIX is *not*, the building blocks, the sixteen
  Role Attributes, the application procedure, and a section on using it for an
  AI-agent organisation that separates what transfers from what degenerates.
- `references/patterns.md` — Base types, Forum types, role attributes grouped,
  relation to Team Topologies / Spotify / holacracy, and the part Appelo
  himself flags as hypothetical.

Validated in first use: mapping a six-circle design onto Crew types exposed a
missing **Partnership Crew** — the outside supplier network that supplies all
of JetThoughts' delivery capacity, owned by nobody and recorded nowhere.
