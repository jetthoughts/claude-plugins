# Upwork scam guard

Start at 0, add the points for each flag seen on the live job page, cap at 100.
Score ≥ 40 fails the job (Stage 3). Flags marked † also mean: tell Paul in the session log so he can
report the post; you never use the report button yourself.

| # | Flag | Points |
|---|---|---|
| 1 | Payment method not verified | +25 |
| 2 | Client joined the same day the job was posted | +15 |
| 3 | No hires and more than 3 open jobs | +15 |
| 4 | Hire rate 0% with 5 or more jobs posted | +15 |
| 5 | Vague post: under 60 words, no deliverable, no technical detail | +10 |
| 6 | Budget far above or below the market for the described scope | +10 |
| 7 † | Asks to move to Telegram, WhatsApp, email or another site before a contract | +35 |
| 8 † | Free work, unpaid test, upfront fee, or equipment purchase | +35 |
| 9 † | Asks for personal data (ID, bank, SSN) in the post or the screening questions | +35 |
| 10 | Reviews look farmed: many tiny jobs with generic praise in a short window | +20 |
| 11 | Client country does not match the post text | +5 |
| 12 | Many proposals but nobody interviewed after 48 hours | +10 |
| 13 † | Crypto, reshipping, review farming or "easy money" language | +35 |
| 14 | Same job reposted by a new client | +10 |
| 15 † | Asks to clone, run or install a repository or package as a coding test before a contract (malware lures aimed at developers, reported 2026) | +35 |

A new client with verified payment and no history is not a scam signal by itself; score it on
the post and keep it if the rest is clean.

Sources: Kimi gig-hunter scam stage (vault research 2026-10-13-kimi-upwork-gig-hunter, workflow/03),
Upwork "Spotting fake job posts" and "Scams FAQ", developer coding-test malware reports (2026).
