# EOS-Lite Methodology (why the loop is shaped this way)

EOS-lite is a stripped-down Entrepreneurial Operating System for a lean operation: an
accountability chart, one quarterly OKR, a handful of 90-day rocks, a weekly scorecard, an IDS
issues list, and a simple pipeline. It exists to make a small team's execution honest and legible
across time — especially when work happens in separate sessions and no one holds full state in
their head.

## Non-negotiable principles

1. **Blanks, not guesses.** A metric with no wired data source stays blank and becomes an Issue.
   Guessed numbers make the scorecard lie, which is worse than an obvious gap. The fix for a blank
   is wiring the source (a booking link, a sheet), not inventing a value.

2. **One issue per week (IDS).** Identify, Discuss, Solve the single highest-leverage blocker.
   A growing issues list is a symptom that the loop stopped solving; keep it short by force.

3. **Rocks need a next action.** A 90-day priority with no named next action + owner is stalled,
   not "in progress." Surfacing that is the point.

4. **Human-path work is what counts.** In a sales operation, the metrics that matter are the
   human-gated ones (calls booked, deals signed). Do not let easy-to-produce output (content,
   docs) masquerade as progress toward the goal.

5. **Cold-eyes before Done (4-eyes, calibrated).** Independent review scales with reversibility:
   light devil's-advocate for internal/reversible items, heavy adversarial review for
   public/irreversible/expensive ones. The reviewer is never the author. Paste the verdict verbatim.

## The loop vs the OKR skill

Use `lark-okr` methodology when wording or restructuring the quarterly OKR (crisp Objective,
measurable KRs). This skill runs the weekly *review* of that OKR and the rest of the OS; it does not
own OKR authoring.

## Anti-patterns this skill refuses

- Marking a card/rock Done by self-certification.
- Filling a scorecard cell with an estimate to avoid a red.
- Running a content sprint while a human-critical-path card is stalled.
- Letting the issues list grow instead of solving the top one.
